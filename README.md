# Programa-Git

## Organización del repositorio

Este repositorio contiene los desarrollos correspondientes a las diferentes evidencias y versiones del proyecto.

Para mantener una organización clara del trabajo, se decidió utilizar diferentes ramas según la actividad o versión desarrollada.

### Estructura de ramas

| Rama     | Uso                                                                                                                          |
|----------|------------------------------------------------------------------------------------------------------------------------------|
| `master` | Rama base y libre del repositorio. Se conserva como referencia inicial y no se utiliza para el desarrollo de las evidencias. |
| `main`   | Rama utilizada para el desarrollo correspondiente a **EV01**.                                                                |
| `EV02`   | Rama utilizada para el desarrollo correspondiente a **EV02**, incluyendo el proyecto **CulturaTechBgEV02**.                  |

### ¿Por qué se dejó `master` como rama base de referencia?

La rama `master` se mantiene sin utilizar para el desarrollo de las evidencias con el propósito de conservar una rama base del repositorio.

Esta decisión permite diferenciar claramente el contenido original del repositorio de los desarrollos realizados posteriormente. De esta manera, `master` funciona como referencia y no interfiere con las ramas utilizadas para las actividades.

Además, se decidió trabajar con `main` y `EV02` de manera independiente para mantener separados los desarrollos correspondientes a cada evidencia.

### Desarrollo por evidencias

#### EV01 — Rama `main`

La rama `main` contiene el desarrollo correspondiente a **EV01**.

En esta rama se realizaron los cambios y avances relacionados con la primera evidencia del proyecto.

#### EV02 — Rama `EV02`

La rama `EV02` contiene el desarrollo correspondiente a **EV02** y el proyecto:


#### CulturaTechBgEV02

Esta separación permite continuar el desarrollo de EV02 sin modificar directamente el contenido asociado a EV01.

#### Esquema del repositorio

```text
master
  │
  ├── main
  │     └── EV01
  │
  └── EV02
        └── CulturaTechBgEV02
```

**Nota:** master se conserva como rama base de referencia, mientras que **main y EV02** se utilizan para los desarrollos específicos de las evidencias.

Objetivo de la organización
La estructura de ramas busca facilitar:

La separación de los trabajos correspondientes a cada evidencia.
El seguimiento independiente de los cambios.
La identificación clara de cada versión del proyecto.
La conservación de una rama base (master) sin mezclar los desarrollos de las evidencias.
La organización del proyecto para su revisión y entrega.
